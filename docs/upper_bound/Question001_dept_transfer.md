## 表單原文關鍵段落

```
系所審核：原就讀系所主管審核意見（同意/不同意轉出） | 擬轉入就讀系所主管審核意見（同意/不同意轉入）
教務處審核：註冊組承辦人 → 註冊組組長 → 教務長
※說明：
  2. 碩士班學生於修業第二學年開始前，得經原肄業所及擬轉入所雙方主管同意，申請轉所，並以一次為限。
  4. 碩士班轉所申請期間：上學期為12月1日至12月31日止；下學期為6月1日至6月30日止。
  5. 申請案經學生原就讀系所及轉入所同意並送教務處複核後，註冊組據以處理學籍等後續事宜。
  6. 學生申請轉所當學期不得休學，若於申請核准後，辦理休學者，其轉所自始無效。
```

## Gold Standard 答案

碩士班轉系所需經：(1) 原就讀系所主管同意轉出、(2) 擬轉入系所主管同意轉入、(3) 教務處三層審核（註冊組承辦人→組長→教務長）。申請期間為上學期 12月1日至12月31日、下學期 6月1日至6月30日，以一次為限。核准後不得再申請更改或轉回原所，申請當學期不得休學。
