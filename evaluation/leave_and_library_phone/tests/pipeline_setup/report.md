## 發現

1. **複合題可以拆成兩部分看**：A、B 部分各自的 Completeness 在 `part_scores.py` 一目了然（`only_phone`：A=0、B=0.857；`wrong_phone`：A=0.283、B=0.286），比只看總分更能看出是哪一半答錯。
2. **電話寫錯原本只會判 miss，現在判 wrong（流程測試找到並修好）**：第一版的 `line` 比對只回 hit／miss，`wrong_phone` 的 63223 被當成「沒說」。使用者指出原本的規則版（姓名配分機、樓層、出納組分機）都能分辨「沒說」與「說錯」，所以補上：寫了號碼但不對（同一行有這條電話的標籤字眼，而號碼不在登記表）判 wrong，沒寫判 miss；錯誤只算給自己的那一條（寫對 63222、寫錯「綜圖 50108」時，只有綜圖是 wrong，商圖、傳圖沒寫仍是 miss）；登記表其他單位已知的電話（如出納組 62123）不算錯誤號碼。補了測試（`test_registry.py` 的 `CheckLineTest`）。規則版與判斷版對 `wrong_phone` 的 K61、K62、K64 都判 wrong。
3. **標籤與號碼綁在一起（使用者要求，像姓名與分機）**：每個號碼看它前面最近的標籤字眼（12 個字內）：標籤後面接的是這條自己的號碼 → hit，接的是別條或不在登記表的號碼 → 這條 wrong（並且不會讓號碼原本所屬的那條誤得分）；沒有標籤的號碼出現就算命中；「(02)總機 轉分機 63222」把分機算給總機前面的標籤；「總圖與綜圖分別是 63222 與 50107」這種列舉不判錯。例：寫「綜圖分機 63222」→ 綜圖 wrong、總圖 miss（原本會誤給總圖 hit）。電話只比數字，所以「(02)2939-3091 轉分機 63222」同時命中總機與總圖分機（K61、K63），設計如此。已知限制：標籤和號碼隔超過 12 個字時配不到，退回「沒標籤」的做法（不會誤判錯，只是抓不到）。
4. **典藏閱覽組直撥電話的資料矛盾已查證**：頁面顯示 (02)2938-7878，連結的 `tel:` 目標是學校總機；現場（2026-11-13，動態）與統計系兩份頁面都支持顯示文字。這題用顯示文字。
5. **「必要」與「選擇性」仍不影響評分**（議題 F8、F9）：K61 列為必要，其餘電話選擇性，但分母都算。
